## 修复的问题

### 问题1：AssetMetric查询返回多行

**位置**：`app/services/research_service.py:47-52`

**原因**：查询缺少 `.limit(1)`，导致 `.scalar_one_or_none()` 失败

**修复**：
```python
# 修复前
metric = await db.execute(
    select(AssetMetric)
    .where(AssetMetric.asset_id == asset_id)
    .order_by(desc(AssetMetric.calculated_at))
)

# 修复后
metric = await db.execute(
    select(AssetMetric)
    .where(AssetMetric.asset_id == asset_id)
    .order_by(desc(AssetMetric.calculated_at))
    .limit(1)
)
```

### 问题2：_calculate_confidence查询返回多行

**位置**：`app/services/research_service.py:283-288`

**原因**：同上，缺少 `.limit(1)`

**修复**：添加 `.limit(1)`，确保只返回最新的指标记录
